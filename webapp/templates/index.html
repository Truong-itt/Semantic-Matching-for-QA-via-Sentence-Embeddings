📖 About This Project
🎯 Task

Sentence Selection QA — Given a question and a context paragraph, the system selects the single sentence most likely to contain the answer.

📚 Dataset

SQuAD v1.1 — 87 k training samples. Converted from span-extraction format by locating which sentence contains the answer span.

🧮 Encoder (this demo)

TF-IDF + Truncated SVD (256-dim). Lightweight, no GPU needed. Optionally upgradeable to Sentence-BERT for higher accuracy.

📐 Metrics

Cosine Similarity — angle between vectors, scale-invariant.
Euclidean Distance — straight-line distance, magnitude-sensitive.

🔄 Pipeline

1
Sentence Tokenise

→
2
Encode

3

→
4
Select
argmax → highest scoring sentence
